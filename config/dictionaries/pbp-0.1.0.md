# Data dictionary

Schema version: `0.1.0`. Generated by `nba-data dictionary`; edit contracts.py, then regenerate.

All fields must be present. Nullable fields use explicit null; missing fields are errors. IDs are nonempty strings and must never be coerced to integers. UTC timestamps require extended `YYYY-MM-DDTHH:MM:SS` format, optional dot fractions of 1–6 digits, and `Z` or `+00:00`. Basic/week dates, comma fractions and `-00:00` are rejected. Integer values use signed 64-bit storage in Parquet outputs; number values use float64. Strings/lists/maps retain their JSON meaning.

Primary keys are scoped by dataset version unless noted. References resolve within the same release; event and period references additionally require game_id. Player boxes reference the composite game_players membership. Field checks do not enforce foreign keys, uniqueness, lineup correctness or release completeness; dataset validation must enforce these separately.

All normalized/derived tables carry complete raw lineage, quality and availability fields. Unknown input availability propagates to unknown derived availability. Otherwise derived available_at is the latest input available_at. Approximate assumptions must remain separate from strict evidenced replay. Official statistics are never overwritten by reconstructed values.

Coverage has separate execution and quality states: pending/running products are partial with a reason, not valid; failed products are failed; not-applicable products are partial with an explanation. A completed product may be valid, partial or failed. Missing source coverage remains a gap. A valid release alone does not imply coverage_complete.

## Interpretation and derivation guide

Canonical event order is canonical_sequence, not a sort by remaining clock or numeric provider ID. source_sequence preserves source-array position; source IDs and original values remain in the pinned raw payload. Only validity=effective contributes to effective statistics; original timelines retain superseded, overturned and unresolved rows. See [normalization and correction rules](normalization.md).

Stint event bounds are half-open [start_sequence, end_sequence); remaining-clock duration is start_clock_ms minus end_clock_ms. Preserve zero-duration event intervals. Player stints, team-lineup stints and matchup stints have different grains: sum each once; use bridge overlap durations when crossing grains. Game-clock rest excludes quarter breaks and halftime. See [stints](stints.md) and [lineup attribution](lineups.md).

Whole possessions are counted once in v_possessions. Segments carry fractional allocated_possessions and must not each receive a whole count. Event-time points and foul-time free-throw attribution are distinct conventions. See [possessions](possessions.md) and [summary reconciliation](summaries.md).

Shot coordinates are native source values; unknown coordinate/distance units remain null. Do not infer feet, court orientation or standardized locations from numeric values alone. Official boxes retain original minute strings and precision; reconstructed durations use integer game-clock milliseconds.

Historical queries require exact-revision evidence for all raw and inventory dependencies before selecting windows or aggregating. Current retrieval time is not publication time. Unknown availability yields no strict observation; the named approximate replay policy is a separately labelled assumption. See [availability](historical-availability.md), [runnable research examples](research-queries.md), and the [operational runbook](runbook.md).
